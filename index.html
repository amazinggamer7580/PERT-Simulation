PERT in one minute

Expected timetₑ = (O + 4M + P) / 6
Activity varianceσ² = ((P − O) / 6)²
Schedule probabilityZ = (Target − project mean) / project σ

O = optimistic, M = most likely, P = pessimistic. This model uses the PERT beta distribution for each activity and independent durations.
